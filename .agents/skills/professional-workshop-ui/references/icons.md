# Icons

## Default library

Preferred: **Lucide**

Acceptable alternative: **Tabler Icons**

Do not mix icon families casually.

## Sizes

Typical:

```text
14–16 px   secondary controls
16–18 px   toolbar actions
18–20 px   rare high-emphasis actions
```

Avoid oversized icons in desktop inspectors.

## Icon-only controls

Use icon-only buttons for familiar actions such as:

- close
- duplicate
- delete
- visibility
- lock
- settings
- expand/collapse

Requirements:

- tooltip
- accessible name
- consistent placement
- adequate hit target even if glyph is small

## Icon + text

Prefer icon + text for domain actions:

- Select cutter
- Recalculate
- Save as preset
- Generate toolpath
- Import dataset

The icon improves recognition; the text preserves clarity.

## No emoji

Do not use emoji as production UI icons.

## Semantic icons

Examples:

```text
check        validated / done
triangle     warning
circle-x     blocking error
info         explanation
sparkles     generated/suggested
save         save/preset
calculator   calculate/recalculate
wrench       machine/tool setup
```

Do not overload one icon with unrelated meanings.

## Icon color

Default icon color should often be neutral.

Use semantic color only when the icon communicates semantic state.
